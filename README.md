# 📊 RetailIQ — Sales & Profit Intelligence Dashboard

RetailIQ is an interactive business intelligence dashboard designed to analyze retail sales, profitability, product performance, regional trends, and shipping metrics. It transforms raw transaction data into actionable insights through interactive visualizations and business analytics.

## ✨ Features

- **Interactive Filters:** Filter data by year, region, and product category.
- **KPI Dashboard:** Track total sales, total profit, orders, and profit margin.
- **Sales Trend Analysis:** Explore monthly sales performance over time.
- **Category Performance:** Compare sales and profitability across product categories.
- **Regional Analytics:** Identify high-performing markets and regions.
- **Product Insights:** Discover top-performing and loss-making products.
- **Business Insights:** Highlight key performance trends and opportunities.
- **Transaction Explorer:** Review filtered records for deeper analysis.

## 🛠️ Technology Stack

- Python
- Pandas
- Plotly
- Streamlit

## 🚀 Getting Started

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Prepare the dataset

Place the permitted dataset at `data/superstore.csv`.

### 3. Launch the dashboard

```bash
streamlit run app.py
```

The application will open in your browser.

## 📈 Business Value

RetailIQ helps users explore sales trends, evaluate profitability, identify product-level opportunities, compare regional performance, and understand operational metrics to support data-driven business decisions.
